# 横截面选股模型特征元数据筛选清单

## 1. 筛选口径

本清单面向 A 股日频或周频横截面选股。字段分为四种用途：

- **F：直接或经简单变换入模**，如估值比率、ROE、行业、事件类型。
- **D：派生特征原料**，如价格、成交额、资产负债表科目，通常需要计算收益率、比例、变化率或滚动统计。
- **U：股票池、风险控制或样本过滤**，如上市状态、ST、停复牌、涨跌停、指数成份。
- **K：连接键与时点控制**，如 `InnerCode`、`CompanyCode`、`TradingDay`、`InfoPublDate`；不作为数值特征直接入模。

核心时点原则：任何记录只能从其首次可公开时间开始生效。优先使用 `InfoPublDate`、`InsertTime`、`TradingDay`；财务数据不能仅按 `EndDate` 回填。修订数据须保留版本，回测使用当时可见版本。

推荐派生字段：

- 收益/动量：1、5、10、20、60、120、240 日收益，跳过最近 5/20 日的中长期动量，隔夜与日内收益。
- 反转/位置：短期反转、距 20/60/250 日高低点、52 周高点距离、连续上涨/下跌天数。
- 波动/尾部：实现波动率、下行波动率、最大回撤、偏度、峰度、涨跌停频率、特异波动率。
- 量价：成交量/额变化、量价相关、OBV 类指标、价格冲击、成交笔均金额、零成交/零收益比例。
- 流动性：换手率、换手波动、Amihud、成交额对数、流动性反转、自由流通市值调整后的换手。

| `LC_Business` / 公司经营范围与行业变更 | 主业类别、变更类别和日期；文本另做 NLP |
| `LC_PurchaseAndSale` | 采购、销售对象及金额、占比等结构化字段 |

派生：收入多元化、主营集中度、地区集中度、前五客户/供应商集中度、集中度变化、毛利结构变化、客户供应商重合及关联方风险。

### 2.14 研发、资本开支与无形资产

| 来源表 | 建议字段 |
|---|---|
| 利润表及科创板研发费用表 `LC_STIBRDExpens` | 研发费用、资本化研发、研发人员、研发项目数量等数值字段 |
| `LC_IntangibleAssetNew`, `LC_IntAssetsDetail` | 无形资产类别、原值、累计摊销、减值、期末余额、增减变动 |
| `LC_FixedAssetsDepreciation`, `LC_CapitalInvest` | 固定资产原值、折旧、资本开支、在建工程、项目投入 |

派生：研发强度、研发资本化率、研发增长、资本开支/资产、折旧/固定资产、无形资产占比、投资强度与未来增长代理。

### 2.15 重大事项、风险与事件特征

事件表应按证券—公告日聚合为过去 20/60/250 日的次数、金额/市值、方向、严重度和距最近事件天数。

| 事件类别 | 来源表 | 建议字段 |
|---|---|---|
| 违规处罚 | `LC_ViolatiEvent`, `LC_ViolatiProcess`, `LC_MajorPunishALL` | 事件类型、责任主体、处罚类型、处罚金额、进程、发生/公告日期 |
| 诉讼仲裁 | `LC_SuitArbitration` | 原告/被告角色、涉案金额、占净资产比例、案件状态、日期 |
| 对外担保 | 担保明细 | 担保金额、担保对象、关联关系、是否逾期、公告日期 |
| 关联交易 | `LC_RelatedTrade`, `LC_Relationship` | 交易类型、金额、占比、关联方类型、定价方式、公告日期 |
| 并购重组 | `LC_Regroup`, `LC_FinancingMergers`, `LC_Merger`, `LC_TenderOffer` | 交易方向、标的、金额、支付方式、进程、成功/终止、公告日期 |
| 重大合同 | `LC_MajorContract` | 合同金额、占收入比例、合同类型、履约期限、公告日期 |
| 补贴与税负 | `LC_Subsidy`, `LC_Tax`, `LC_TaxChange` | 补贴金额、计入损益金额、税率/税负变化及公告日期 |
| 委托理财、借贷、资产托管 | `LC_EntrustInv`, `LC_Credit` 等 | 金额、期限、利率、对象、关联属性、收益/损失、公告日期 |

### 2.16 停复牌、涨跌停、可交易性与样本过滤

| 来源表 | 建议字段 | 用途 |
|---|---|---|
| `LC_SuspendResumption` / 停牌复牌表 | 停牌日期时间、复牌日期时间、停牌类型、原因、公告日 | U/F：不可交易过滤、停牌事件、停牌时长 |
| `QT_PerformanceData` | `StockBoard`, `LimitBoard`, `SurgedLimit`, `DeclineLimit` | U/F：下一交易时点无法成交或成交偏差控制 |
| 证券主表、上市状态、特别处理 | 上市/退市、ST、板块、上市日期 | U：股票池过滤 |
| `LC_SharesFloatingSchedule` | 解禁日期与数量 | U/F：供给冲击与成交约束 |

### 2.17 金融行业专属指标

银行、保险、证券公司不能只使用一般工商企业的存货周转等指标。模型若包含金融股，应增加行业专属特征或分行业建模。

| 行业 | 来源表 | 应保留字段族 |
|---|---|---|
| 银行 | `LC_BankLoan`, `LC_BankRegulator`, `LC_BankIncomeExpense`, `LC_BankAssetsLiability` | 贷款和存款规模/增速、净息差、净利差、不良贷款率、拨备覆盖率、资本充足率、核心一级资本充足率、流动性比例、成本收入比、逾期与关注类贷款、同业资产负债 |
| 保险 | `LC_EmbeddedValue`, `LC_EmbeddedValueChange`, `LC_EmbeddedValueIndex`, `LC_FSpecialIndicators` | 内含价值、新业务价值、保费收入、赔付率、费用率、综合成本率、偿付能力、投资收益率、准备金等 |
| 证券 | `LC_FinanceSpecialIndexSC`、证券公司月度主要财务指标 | 营业收入、净利润、净资本、风险覆盖率、流动性覆盖率、净稳定资金率、经纪/投行/资管/自营收入结构等 |
| 金融通用 | `LC_FinanceIndex`, `LC_FSDerivedData`, `LC_FSpecialIndicators` | 金融类盈利、资本、杠杆、资产质量、流动性和成长数值字段 |

### 2.18 市场、指数与宏观状态（日期级公共特征）

这些字段在同一交易日对所有股票相同，不能解释当日纯截面差异，但适合与个股暴露做交互、用于动态模型或市场状态分层。

| 来源 | 字段 |
|---|---|
| 指数行情、中证指数行情 | 指数收益、波动、成交额、估值、宽度、趋势 |
| 指数成份和权重 | 个股指数归属、权重、纳入/剔除事件 |
| 利率、收益率曲线、货币市场 | 无风险利率、期限利差、信用利差、资金利率 |
| 期货行情 | 股指期货基差、期限结构、持仓量、成交量 |

## 3. 不应直接作为特征的字段

- 纯技术字段：`ID`, `JSID`, `XGRQ`, `UpdateTime`, `InsertTime`。其中更新时间只用于版本和时点控制；不得让回测看到未来修订时间。
- 连接标识：`InnerCode`, `CompanyCode`, `SecuCode`、公告编号、事件编号。只用于关联，不能作为连续数值入模。
- 名称和联系方式：公司名、简称、姓名、地址全文、电话、邮箱、网址；地域和人员属性应先结构化。
- 信息来源、备注、全文、原因描述等高维文本：除非建设严格按公告日切分的 NLP 管线，否则不与表格模型混用。
- 未来已知字段：实施完成日、最终回购金额、最终处罚结果、实际解禁量等，在当时尚未公布时不得回填。
- 标签同源字段：预测未来收益时，未来窗口的价格、最高最低价、未来停牌/退市结果、事后指数成份等必须排除。
- 同义和重复口径：旧准则/新准则、合并/母公司、快报/正式报表、数据库指标/自算指标只保留明确主口径，其余用于校验或版本特征。

## 4. 推荐的最终特征层级

### L0：股票池和时点层

证券主键、交易日、上市状态、ST、停牌、涨跌停、上市天数、行业、板块、指数成份。该层决定样本是否可训练和可交易。

### L1：核心日频层

价格收益、动量/反转、波动、流动性、成交行为、市值、估值、行业相对值。覆盖率最高，适合作为基线模型。

### L2：点时财务层

盈利、成长、质量、偿债、营运、现金流、投资、研发、资产增长；统一转换为单季、TTM、同比、环比和行业分位数。

### L3：持仓与事件层

股东户数、集中度、机构/北向持股、质押、融资融券、回购、增减持、解禁、分红、再融资、业绩预告/快报、龙虎榜和大宗交易。

### L4：治理、供应链和风险增强层

激励、员工、客户供应商集中度、控制人、高管、违规、诉讼、担保、关联交易、并购重组、补贴和重大合同。

## 5. 数据落地必需字段

每张点时表至少标准化为以下元数据：

```text
security_id / company_id
effective_date            # 记录代表的业务生效日或报告期
announcement_datetime     # 市场首次可知时间，最重要
available_trade_date      # 按盘前/盘后规则映射到首次可交易日
end_date                  # 报告期末或事件截止日
version_id / update_time  # 仅用于版本控制
source_table
field_name
field_value
unit
accounting_standard
consolidation_flag
report_type
```

财报建议采用“公告时间 as-of join”；行情采用 `TradingDay`；行业、股本、指数成份和状态类数据采用有效期区间连接。所有滚动特征先在单股时间序列计算，再在每个交易日做去极值、缺失处理、行业/市值中性化和横截面标准化。

## 6. 覆盖性结论

本清单覆盖 `DataSourceDoc` 中国内上市公司数据库的 15 个一级目录，并补充常量库、指数数据库、融资融券、沪深港通、期货/利率等跨库数据。用于建模时不应只选现有总结文档中的估值、财务、动量 30 项；完整候选空间还应包含股本供给、持仓结构、资金行为、预告快报、治理激励、供应链、重大事件、可交易性以及金融行业专属指标。
