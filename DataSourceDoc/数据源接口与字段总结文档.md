## 四、日截面选股所需的易处理、可解释特征

### 4.1 核心特征分类

#### 4.1.1 估值因子（Valuation Factors）
| 特征名 | 字段来源 | 计算方式 | 经济解释 |
|--------|----------|----------|----------|
| PE | LC_MainIndexNew.EPS | 市值/EPS | 市盈率，衡量股价相对于盈利的高低 |
| PB | LC_MainIndexNew.NetAssetPS | 市值/每股净资产 | 市净率，衡量股价相对于净资产的高低 |
| PS | LC_DerivativeData.OperatingRevenueTTM | 市值/营业收入 | 市销率，衡量股价相对于销售收入的高低 |
| PCF | LC_DerivativeData.NetOperateCashFlowTTM | 市值/经营现金流 | 市现率，衡量股价相对于现金流量的高低 |
| EV_EBITDA | LC_MainIndexNew.EVWtoEBITDA | EV/EBITDA | 企业价值倍数，剔除资本结构影响的估值指标 |
| EP | LC_MainIndexNew.EPS | EPS/市值 | 盈利收益率，PE的倒数 |

#### 4.1.2 盈利因子（Profitability Factors）
| 特征名 | 字段来源 | 计算方式 | 经济解释 |
|--------|----------|----------|----------|
| ROE | LC_MainIndexNew.ROE | 净利润/平均净资产 | 净资产收益率，衡量股东回报 |
| ROE_Cut | LC_MainIndexNew.ROECut | 扣非净利润/平均净资产 | 扣非ROE，剔除一次性损益影响 |
| ROA | LC_MainIndexNew.ROA | 净利润/平均总资产 | 总资产收益率，衡量资产效率 |
| ROIC | LC_MainIndexNew.ROIC | EBIT*(1-税率)/投入资本 | 投入资本回报率，衡量所有资本的回报 |
| GrossMargin | LC_MainIndexNew.GrossIncomeRatio | 毛利/营业收入 | 毛利率，衡量产品定价能力 |
| NetMargin | LC_MainIndexNew.NetProfitRatio | 净利润/营业收入 | 净利率，衡量整体盈利能力 |
| OperatingMargin | LC_MainIndexNew.OperatingProfitRatio | 营业利润/营业收入 | 营业利润率，衡量主营业务盈利能力 |
| EBIT_Margin | LC_MainIndexNew.EBITToTOR | EBIT/营业收入 | EBIT利润率，剔除财务费用影响 |

### 4.2 特征处理建议

#### 4.2.1 数据清洗
1. **缺失值处理**：删除缺失比例过高的样本
2. **异常值处理**：使用Winsorize截断（如1%分位数）
3. **标准化**：使用Z-score标准化或Rank标准化

#### 4.2.2 时序处理
1. **财务数据对齐**：确保财务数据与行情数据日期对齐
2. **滚动窗口**：使用滚动窗口计算动量、波动率等时序特征
3. **滞后处理**：财务指标通常滞后1-2个季度

#### 4.2.3 行业中性化
1. **行业去均值**：减去行业均值或中位数
2. **行业标准化**：在行业内部进行标准化

## 六、数据查询示例

### 6.1 查询最新财务指标
```sql
SELECT 
    CompanyCode,
    EndDate,
    ROE,
    ROA,
    EPS,
    NetProfitRatio,
    OperatingRevenueGrowRate
FROM LC_MainIndexNew
WHERE EndDate = (SELECT MAX(EndDate) FROM LC_MainIndexNew)
ORDER BY ROE DESC
```

### 6.2 查询日行情数据
```sql
SELECT 
    InnerCode,
    TradingDay,
    ClosePrice,
    TurnoverVolume,
    TurnoverValue
FROM LC_STIBDailyQuote
WHERE TradingDay = '2024-03-13'
ORDER BY TurnoverValue DESC
```

### 6.3 查询行业分类
```sql
SELECT 
    InnerCode,
    FstIndNameCSI,
    SndIndNameCSI
FROM LC_CSIIndustry
WHERE EndDate = (SELECT MAX(EndDate) FROM LC_CSIIndustry)
```
