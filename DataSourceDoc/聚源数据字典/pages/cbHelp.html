数据表样例
表名 基金前10名持有人持股信息 MF_TopTenHolder 版本 1.00
说明 基金前10名持有人持有基金份额情况
业务主键：(InnerCode,EndDate,HolderName)
最后修改日期：
序号 列名 中文名称 类型 空否 备注
1 ID ID bigint 否
2 InnerCode 基金内部编码 int 否
3 InfoPublDate 信息发布日期 datetime 是
4 InfoSource 信息来源 varchar(100) 是
5 EndDate 截止日期 datetime 否
6 SerialNumber 序号 int 是
7 HolderName 持有人名称 varchar(100) 否
8 HolderCode 机构代码 varchar(20) 是 注1
9 HoldingVolume 持有份额(份) decimal(18,0) 是
10 HoldingRatio 持有比例 decimal(18,6) 是
11 HolderNature 持有人性质 varchar(50) 是 从表
12 XGRQ 更新日期 datetime 否
从表名 MF_TopTenHolder_SE
序号 列名 中文名 类别
14 HolderNature 持有人性质 varchar
备注说明
【注1】机构代码(HolderCode)：与机构基本资料表（LC_InstiArchive）中的公司代码（CompanyCode）字段关联。
从表 MF_TopTenHolder_SE
序号 列名 中文名 类别
1 ID 对应主表中记录中ID decimal(18,0)
2 TypeCode 对应从表描述中的字段序号 int
3 Code 对应系统常量表或其他表中的代码 int
●每个表列出序号、列名、中文名称、类型、字段空否、备注，对于某个字段进一步说明通过备注项解释。 假如不清楚某个数据项在那个表中，可通过搜索功能，输入中文关键词检索；
●从表对应的表名为:主表名称+“_SE”，例如：基金前10名持有人持股信息（MF_TopTenHolder）表中有一个从表MF_TopTenHolder_SE, 持有人性质（HolderNature）对应的序号是1，则TypeCode = 1； 在从表描述中如没有特别注明什么类别，则都是对应系统常量表中的类别：
select A.InnerCode, A.HolderName,A. HoldingVolume, C.MS
from MF_TopTenHolder A
left join MF_TopTenHolder_SE B on A.ID = B.ID and TypeCode = 1
left join CT_SystemConst C on C.DM = B.Code and C.LB = 1026
通过以上语句就得到了持有人持有份额对应的性质。
